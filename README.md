# TP Final Redes - UNGS

Este repositorio contiene el trabajo práctico final de la materia **Sistemas Operativos y Redes** de la Universidad Nacional de General Sarmiento.

## 📌 Descripción
El proyecto consiste en el **diseño lógico de una red corporativa** para la empresa ficticia *Colosungs*, con sede central y dos sucursales.  
Se definieron subredes, máscaras y configuraciones de routers y switches utilizando **Cisco Packet Tracer**.

## 🎯 Objetivos
- Definir correctamente las subredes necesarias para cada área funcional.
- Determinar máscaras de subred y gateways.
- Configurar routers y switches con VLANs y subinterfaces.
- Implementar protocolo de enrutamiento y pruebas de conectividad.
- Documentar comandos básicos de configuración en Cisco IOS.

## 🛠️ Tecnologías utilizadas
- **Cisco Packet Tracer**
- **Subneteo /23**
- **Routers Cisco**
- **Switches con VLANs**
- **DNS y servidores simulados**

## 📂 Archivos
- `trabajopracticoconvlan.pkt` → Diseño principal de la red.


## 🚀 Cómo abrir el proyecto
1. Descargar el archivo `.pkt`.
2. Abrirlo con **Cisco Packet Tracer**.
3. Explorar la topología y las configuraciones de red.
